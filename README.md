# Praktikum 8 – PHP dan Database MySQL

## 1. Deskripsi Praktikum

Praktikum ini dilakukan untuk mempelajari cara menghubungkan PHP dengan database MySQL menggunakan XAMPP dan phpMyAdmin.

Pada praktikum ini dibuat aplikasi sederhana untuk mengelola data barang menggunakan operasi CRUD (Create, Read, Update, Delete).

## 2. Tujuan Praktikum

- Memahami koneksi PHP dengan database MySQL.
- Membuat database dan tabel menggunakan phpMyAdmin.
- Menampilkan data dari database.
- Menambahkan data barang.
- Mengubah data barang.
- Menghapus data barang.
- Menampilkan gambar barang.

## 3. Database

Nama database: `latihan1`

Nama tabel: `data_barang`

Kolom pada tabel:
- `id_barang`
- `kategori`
- `nama`
- `gambar`
- `harga_beli`
- `harga_jual`
- `stok`

## 4. Fitur Aplikasi

Aplikasi ini memiliki beberapa fitur, yaitu:

1. **Read:** Menampilkan daftar barang dari database.
2. **Create:** Menambahkan data barang baru.
3. **Update:** Mengubah data barang yang sudah tersimpan.
4. **Delete:** Menghapus data barang dari database.
5. **Gambar Barang:** Menyimpan file gambar produk di folder gambar dan menampilkan gambar pada halaman aplikasi.

## 5. Struktur Folder

```text
lab8_php_database/
│
├── gambar/
│   ├── samsung.jpg
│   ├── xiaomi.jpg
│   └── oppo.jpg
│
├── index.php
├── koneksi.php
├── tambah.php
├── ubah.php
├── hapus.php
└── style.css
```

## 6. Cara Menjalankan Aplikasi

1. Jalankan Apache dan MySQL melalui XAMPP.
2. Buat database dengan nama `latihan1` di phpMyAdmin.
3. Buat tabel `data_barang` beserta kolom-kolomnya.
4. Simpan folder project di dalam folder `htdocs`.
5. Buka browser.
6. Masukkan alamat berikut:

`http://localhost/lab8_php_database/index.php`
